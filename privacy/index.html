01

Privat saat dibuat. Publik saat kamu memilih.

stickerio adalah aplikasi Android untuk membuat stiker dari foto, GIF, dan video. Pengeditan dan paket privat berada di perangkatmu. Paket hanya dikirim ke layanan stickerio ketika kamu memilih untuk memublikasikannya. Kami tidak meminta kamu membuat akun, memasukkan alamat email, atau login.

Kebijakan ini menjelaskan aplikasi stickerio, fitur publiknya, serta situs ini. “Penerbit” berarti pengelola stickerio yang identitas dan kontaknya dicantumkan pada bagian kontak.

02

Foto, GIF, video, dan penyimpanan lokal

Aplikasi membaca media yang kamu pilih melalui pemilih media Android. File asli tidak diubah. Teks, coretan, perubahan posisi, crop, dan hasil stiker diproses di perangkat. Audio video tidak disertakan dalam stiker bergerak.

Koleksi, preferensi tampilan, salinan paket unduhan, serta cache pratinjau disimpan di penyimpanan aplikasi. Kamu dapat menghapus paket lokal melalui aplikasi. Menghapus data aplikasi atau mencopotnya menghilangkan koleksi lokal; salinan yang sudah masuk WhatsApp atau tersimpan di luar aplikasi dikelola terpisah.

03

Data yang dikirim saat memakai fitur publik

Jika kamu memilih publikasi, layanan menerima stiker, sampul, nama paket, deskripsi, tag pencarian, jenis paket, versi, dan metadata stiker yang disertakan, seperti emoji atau teks aksesibilitas. Paket publik dapat ditemukan, dilihat, diunduh, dan dibagikan pengguna lain. Tag juga dapat ditampilkan sebagai saran pencarian. Jangan memublikasikan konten yang tidak kamu ingin orang lain akses.

Menandai favorit dan mengimpor paket publik ke WhatsApp dapat mengirim ID paket beserta identitas instalasi. Server menyimpan hubungan favorit dan pencatatan impor per instalasi untuk daftar favorit dan jumlah popularitas. Membuat paket privat tidak mengunggah isi paket.

Permintaan internet menampilkan alamat IP kepada server. Backend menggunakan alamat peer koneksi untuk pembatasan laju permintaan dalam memori. Penyedia jaringan, hosting, atau proxy juga dapat memproses informasi teknis permintaan sesuai konfigurasi dan kebijakan mereka.

04

Identitas instalasi, bukan akun login

Fitur publik menggunakan ID dan kunci acak yang dibuat untuk instalasi aplikasi. Ini bukan IMEI, nomor telepon, atau ID perangkat keras. Kunci disimpan secara lokal tanpa backup aplikasi; server menyimpan hash kunci untuk memeriksa kewenangan pengelolaan paket.

Menghapus data aplikasi, kehilangan perangkat, atau mencopot aplikasi dapat menghilangkan identitas tersebut. Tidak ada login atau pemulihan kepemilikan otomatis. Menginstal ulang tidak mengembalikan akses pengelolaan paket lama dan tidak otomatis menghapus publikasi maupun catatan identitas di server.

05

Layanan yang terlibat

Backend stickerio mengelola katalog, publikasi, favorit, dan popularitas. Media paket publik disimpan di Cloudflare R2 dan diakses melalui backend. Kredensial penyimpanan R2 tidak disertakan dalam aplikasi.

Hapus latar otomatis memakai Google ML Kit dan Google Play Services untuk pemrosesan pada perangkat. Layanan tersebut dapat mengunduh model serta mengirim data perangkat, aplikasi, pengenal diagnostik, konfigurasi API, dan metrik performa/penggunaan sesuai dokumentasi Google.

Saat kamu memilih menambahkan paket ke WhatsApp, stickerio memberi WhatsApp akses baca ke paket yang dipilih. Penggunaan serta salinan di WhatsApp tunduk pada kebijakan WhatsApp. Aplikasi saat ini tidak memasang iklan, SDK analitik aplikasi tersendiri, atau penjualan data sebagai fitur.

06

Penyimpanan dan penghapusan

Paket publik disimpan selama dipublikasikan. “Jadikan privat” menghapus paket dari katalog dan menutup akses unduhan API. Berkas penyimpanan dijadwalkan untuk dihapus; antrean dapat mencoba ulang jika penghapusan gagal. Data terkait paket, termasuk indeks tag dan catatan favorit/impor paket tersebut, dihapus dari basis data saat publikasi dibatalkan.

Salinan yang sudah diunduh, diekspor, atau dibagikan orang lain tidak dapat ditarik kembali oleh stickerio. Catatan identitas instalasi di server tidak otomatis terhapus ketika aplikasi dicopot atau satu paket dijadikan privat; saat ini belum ada tombol penghapusan seluruh identitas server.

Cache lokal dapat dibersihkan sistem atau melalui penghapusan data aplikasi. Informasi teknis di hosting atau layanan pihak ketiga mengikuti konfigurasi retensi mereka; tidak ada janji periode penghapusan tertentu yang dibuat di halaman ini. Untuk pertanyaan data atau permintaan penghapusan lain, gunakan kontak penerbit setelah informasi kontak tersedia.

07

Pengiriman data dan batas keamanan

Akses pengelolaan paket diperiksa menggunakan kredensial instalasi. Namun, build deployment saat dokumen ini disiapkan mengakses backend melalui HTTP pada alamat IP, sehingga lalu lintas fitur publik, termasuk kredensial instalasi, tidak dilindungi enkripsi TLS selama pengiriman. Kebijakan ini tidak menyatakan bahwa seluruh koneksi aplikasi terenkripsi.

Jangan membagikan kunci instalasi atau memasukkan informasi sensitif ke paket publik. Tidak ada metode penyimpanan atau pengiriman yang menjamin keamanan mutlak.

08

Situs ini

Kode situs ini tidak memasang cookie analitik, pelacak iklan, formulir pengumpulan data, font jarak jauh, atau penyimpanan lokal untuk pelacakan. Aset visual dan font sistem dimuat tanpa layanan analitik tambahan. Penyedia hosting tetap dapat menerima IP, user agent, waktu akses, dan URL yang diminta sebagai bagian dari pengiriman halaman.

Tautan ke Google, Cloudflare, WhatsApp, atau toko aplikasi akan membuka layanan lain dengan kebijakan masing-masing.

09

Perubahan kebijakan

Isi kebijakan dapat diperbarui ketika fitur atau praktik pengolahan data berubah. Tanggal pembaruan tercantum di halaman ini. Perubahan yang membutuhkan pemberitahuan atau persetujuan tambahan akan ditangani sesuai kewajiban yang berlaku.
